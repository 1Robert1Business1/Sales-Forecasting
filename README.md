# Sales Forecasting — UK Sports Bar (Synthetic Data)

> Forecasting daily sales for a sports bar, and turning that forecast into an
> ordering and staffing decision.

**Status:** in active build. README is written last, from real results.
See [`PROJECT_BRIEF.md`](./PROJECT_BRIEF.md) for the full spec.

> **Data is synthetic and clearly labelled as such.** Generated by a seeded
> script (`src/generate_data.py`). No real commercial figures are used.

## Quick start (Windows / PowerShell)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Quick start (macOS / Linux)

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```
